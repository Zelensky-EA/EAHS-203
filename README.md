# Everett Alvarez Science Department Inventory website

Replace the index.html file served by your Git website with the index.html in this folder, then commit and publish the change. This page opens your existing Google Apps Script deployment automatically. It also provides an Open shared inventory button as a fallback.

Use your school Google account when Google prompts you to sign in. The application and its inventory records are served by the existing Apps Script deployment and department Google Sheet.

If your website publishes from a docs folder or another directory, replace index.html in that published directory. If it uses a build system, use this page as the resulting published index.html.

No Apps Script code changes or new deployment are needed for this website redirect. The deployed application must already be authorized and accessible to the intended staff.
